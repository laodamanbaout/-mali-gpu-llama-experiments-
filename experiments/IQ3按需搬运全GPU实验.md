# IQ3_S 模型按需搬运：全 GPU 计算实验

日期：2026-11-04。设备为 Redmi K50 / 天玑 8100 / Mali-G610 MC6，Android 14。所有改动都在现有的隔离实验构建中，原模型和原程序没有覆盖。这是针对一台设备、一个模型的实验，不能直接代表所有 Mali 驱动。

## 已经跑通什么

Qwen2.5-7B-Instruct IQ3_S 的权重保存在 CPU 可映射的模型文件中，计算时由 llama.cpp 调度器按需搬运到 Vulkan，复用 GPU 临时空间。IQ3_S 成功完成英文 16 token 续写，以及中文对话问题的 32 token 生成。调度日志中计算图分成 340 段，记录的段全部标为 Vulkan0，包括词嵌入、模型层和输出层；这说明所记录的模型计算图运行在 GPU。CPU 仍参与文件管理、数据搬运、分词、图调度和采样，因此这不是整个程序完全不用 CPU，也不是全部权重常驻 GPU。

另外，直接通过下方启动器的对话模式，IQ3_S 也完成同一中文题目的 32 token 生成，输出中明确出现“他还剩4本”。该次退出码为 0，所记录的 5100 条调度分段均为 Vulkan0。该路径依赖此前为设备实现的 Vulkan 队列兼容，以及受限的大 Q5_K、Q6_K 矩阵和单 token 矩阵分块实验开关；不是原版 llama.cpp 在任意旧 Mali 设备上的通用保证。

## 具体观察

| 测试 | 结果 | 边界 |
| --- | --- | --- |
| IQ3 英文续写，最多 16 token | 完成，生成以“Paris. Paris is a beautiful city …”开头 | 单次实验；逐 token 计算约 0.26 token/秒 |
| IQ3 中文算术，最多 32 token | GPU 和 CPU 都在中间步骤得到“剩下四本” | 两者前 18 个生成 token 相同，随后不同；达到上限时都还没完整结束回答 |
| IQ3 启动器中文对话，最多 32 token | 单轮对话测试完成，生成结果包含“他还剩4本” | 一次测试；输入阶段约 0.80 token/秒，后续计算约 0.26 token/秒，与探针配置不同 |
| 中文问题首 token 的完整词表对照 | CPU/GPU 前 5 个候选顺序一致，分布总变差约 0.00072 | 只覆盖该提示的首个位置，首选概率高度集中；所有词表分数的均方根差约 0.20，不能推断整段或一般精度 |
| 同一中文问题，64 token 输入 | GPU 输入处理约 2.53 token/秒，后续计算约 0.26 token/秒；CPU 分别约 2.21 和 1.83 token/秒 | 各一次，频率和后台条件未严格固定；不能视作稳定性能排名 |
| IQ1 英文提示对照 | 流式 GPU 与此前权重常驻 GPU 的实验路径，首位置 152064 个词表分数逐位相同，8 个生成 token 相同 | 只覆盖一个提示和该配置 |

中文对照题目是：小明原有三本书，收到两本，借出一本，要求简短计算。GPU 的 32 token 截断结果为：“小明原来有三本书，小红送给他两本后有五本，再借给朋友一本后剩下四本。所以，小明”。这是有限的功能验证，并非完整的模型质量测试。

## 内存和系统影响

IQ3 权重约 3331 MiB，通过文件映射放在 CPU 地址空间；一次英文短续写记录的 Vulkan 模型常驻缓冲为 0 MiB、计算缓冲约 431 MiB、上下文约 14 MiB。中文探针使用不同批次，GPU 计算缓冲约 458 MiB。映射并不会缩小模型文件，系统会按需缓存和回收文件页。

英文 16 token 测试中，每两秒采样得到的最低 `MemAvailable` 为 3,801,548 KiB；中文 32 token GPU 探针最低为 3,712,972 KiB；启动器中文对话最低为 3,620,064 KiB。`MemAvailable` 包括可回收的文件缓存，并非同等大小的立即空闲物理内存；采样也可能漏掉短暂波动。测试设置了低于 700,000 KiB 时停止本次推理的监测，不能保证阻止所有系统内存事件。

此前一次未使用文件映射的 IQ3 测试虽然也完成了 4 token，但系统可用内存最低采样约 150,620 KiB，Android 低内存管理器结束了 Termux 和其他后台进程。此路径造成明显系统压力，后续测试改用映射，不建议重复该非映射配置。手机系统原有保护始终开启。

## 复现入口

实验启动器为同目录 `mali-llama-stream.sh`，已安装至手机 Termux 的隔离目录 `~/mali-clean-verify-20261102-lf/mali-llama-stream.sh`。它依赖该目录中的实验版 llama.cpp 和 `large-matvec-experiment` Vulkan 库，不能单独复制到另一台手机即运行。默认将输入视作续写；设置 `MALI_CHAT=1` 可启用模型对话模板，设置 `MALI_TRACE_GRAPH=1` 可打印计算图分配。以下在本机 Termux 中使用：

```sh
MALI_CHAT=1 MALI_TRACE_GRAPH=1 bash ~/mali-clean-verify-20261102-lf/mali-llama-stream.sh \
  "$HOME/models/Qwen2.5-7B-Instruct.i1-IQ3_S.gguf" \
  '小明原有三本书，收到两本，借出一本。现在有几本？' 32
```

脚本设置 256 token 上下文及 700,000 KiB 内存阈值，默认最多生成 8 token；接受的上限 256 不代表已经验证那么长的生成。检测结果只在采样时有效。阈值模拟测试已在模型加载前触发停止；真实测试也应观察系统状态。实际运行前请确认模型文件名与路径。

## 可审查的原始记录
