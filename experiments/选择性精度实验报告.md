# 天玑 8100：选择性精度实验

日期：2026-11-02。设备为 Redmi K50 / 天玑 8100 / Mali-G610 MC6，模型为 Qwen2.5-7B-Instruct IQ1_S，实验基于此前已跑通完整 GPU 计算图的隔离版本。原模型和原程序均未覆盖。

## 实验改动

在 Vulkan 后端增加默认关闭的 `GGML_VK_EXPERIMENTAL_MALI_FP32_QUANTS=1`。本次只在 ARM GPU、无协作矩阵的设备路径下，对 IQ1_S 和 Q4_K 的部分矩阵乘法选用已有的 FP32 着色器；相应的共享内存检查按 FP32 所需空间计算。其它量化格式和单向量路径继续使用现有选择逻辑。

这不是通用的 Mali 修复，也不表示整个模型都用 FP32。该开关只在进程启动前设置才参与设备初始化和着色器选择；本次结果只覆盖该手机、驱动、模型和测试输入。代码差异为 `layer-trace/selective-fp32-experiment.patch`，需在先前的 `prompt-suite/upstream-to-experiment.patch` 和 `gpu-placement/large-q5-experiment.patch` 之后应用；已在隔离副本上通过补丁适用性检查。

## 正确性与覆盖

采用第一层真实 Q、K、V 权重以及同一份输入进行对照。32 token 批次中，选择性模式的 Q/K/V 全部算子输出分别与全局设置 `GGML_VK_DISABLE_F16=1` 的对应结果逐位一致。在每个矩阵的 256 个抽样点上，对反量化后双精度累加参考的均方根误差分别约为 Q `1.63e-6`、K `9.20e-7`、V `2.24e-7`。这些数字只验证已量化权重的一部分算子计算，不能证明原模型或者全模型推理正确。

同样权重和一个 token 的输入下，选择性模式的 Q/K/V 全部输出与原默认 GPU 结果逐位一致。原默认设置下，Q/K/V 的 32 token 算子输出在本次新旧程序库之间也逐位一致。

补充回归：四个 IQ1_S 的真实模型尺寸随机矩阵用例通过 CPU 对照，大 Q5_K 输出矩阵的 32 token 用例通过现有测试阈值。最初一次尺寸测试未打开测试集开关，实际执行 0 项；已保留该记录，不计入通过数量，重新启用测试集后为 4/4。

完整模型方面，数学（47 token）、中文（35 token）和代码（39 token）输入的选择性模式均完成；日志中模型图为一个 Vulkan0 分段。数学输入的两次完整词表输出逐位一致。实验开关关闭时，修改后程序库对数学输入的完整词表输出与修改前逐位一致。

完整模型的分数仍有差异：数学样本中，选择性完整 GPU 与 CPU 的 softmax 总变差约 0.344；与默认完整 GPU 约 0.114；与全局禁用 FP16 的完整 GPU 约 0.066。CPU 不是绝对真值，这些数字只是分布差异，不能用来宣称某个模式在整模型上更准确。中文和代码样本的 CPU 与选择性 GPU 分布总变差分别约 0.325 和 0.184；各仅一条样本。

## 初步速度对照

同一 5 token 英文提示、16 token 连续生成、全模型计算图 GPU、`-fa off`，三种设置各运行两次。表中数值为日志记录的生成阶段 token/秒，每次为 15 次生成计算；首个生成 token 来自提示处理。电池传感器在这些运行前后约 27.2–28.5°C；没有固定 CPU/GPU 频率、设备热状态或后台负载。

| 设置 | 生成速度（两次，token/秒） |
|---|---:|
| 默认 GPU | 0.57、0.57 |
| 选择性 FP32 | 0.58、0.53 |
| 全局禁用 FP16 加速 | 0.40、0.42 |

同一 47 token 数学输入的提示处理，各运行一次：默认约 1.49、选择性约 1.24、全局禁用 FP16 约 1.20 token/秒。选择性模式在这个样本上有提示处理速度损失；一次结果不足以作稳定性能结论。完整数据与电池温度见 `selective-precision/summary.tsv` 及同目录日志。

## 在当前隔离版本中运行

在手机 Termux 中，先确认模型存在及手机有足够可用内存，然后在新进程中运行：

```sh
export PREFIX=/data/data/com.termux/files/usr
export PATH="$PREFIX/bin:/system/bin"
export EXP="$HOME/mali-clean-verify-20261102-lf/source"
export LD_LIBRARY_PATH="$EXP/build/bin"
export GGML_NO_BACKTRACE=1
export GGML_VK_EXPERIMENTAL_LARGE_Q5_MAT=1
export GGML_VK_EXPERIMENTAL_MALI_FP32_QUANTS=1

"$EXP/build/bin/llama-completion" \
  -m "$HOME/models/Qwen2.5-7B-Instruct.i1-IQ1_S.gguf" \
  -ot 'token_embd.weight=Vulkan0,output.weight=Vulkan0' \
  -c 128 -n 16 -ngl 99 -fa off -t 4 -b 32 -ub 32 \
  --temp 0 -no-cnv --no-warmup -fit off \
  -p 'The capital of France is'
```

实验版本的源码与程序库备份在手机隔离目录中；系统内存保护没有关闭。此命令不适合直接推广给未经验证的其他设备或模型。

- `gpu-placement/iq1-math-full-gpu-selective.log`、带 `selective-repeat` 的日志：完整 GPU 数学样本与重复结果。

后续应使用更多真实权重、不同批次与模型，对比高精度参考，并继续调查融合和逐层采样改变最终分数的原因；在此之前不要将该实验补丁称为生产就绪方案。

2026-11-03 补充：本机一个数学输入中，融合差异已缩小到 FP16 K 缓存的位置编码与写入融合；新增长上下文位置的独立测试及默认关闭的绕行方案，见《位置编码融合排查报告》。
