# 天玑 8100：位置编码与 KV 缓存融合排查

日期：2026-11-03。设备为 Redmi K50 / 天玑 8100 / Mali-G610 MC6，模型为 Qwen2.5-7B-Instruct IQ1_S；除明确说明的单算子试验外，使用完整 GPU 模型计算图并关闭 Flash Attention。原模型和原程序没有覆盖。

## 结果

此前发现，同一数学输入在默认融合和关闭全部融合时输出分布不同。本次对 47 token 输入逐类对照：

| 单独关闭的融合 | 对最终词表分数的影响 |
|---|---|
| RMS_NORM_MUL，114 次 | 与默认逐位一致 |
| MUL_MAT_ADD，1 次 | 与默认逐位一致 |
| ROPE_VIEW_SET_ROWS，56 次 | 与关闭全部融合的结果逐位一致 |

融合追踪本身没有改变该输入的最终分数。这是一个输入的结果，不证明其他模型或其它融合都没有差异。

进一步将 K 缓存设为 FP32 后，在相同模型和输入上，位置编码融合与未融合的完整词表分数逐位一致，也与该输入的 FP16 K 缓存未融合结果逐位一致。此现象不表示两种缓存的全部中间值或其他输入一律相同。

## 独立位置编码试验

从此前模型运行中取得第一层真实 K 中间张量，以同一输入、位置和初始缓存分别执行 CPU、融合 GPU 与未融合 GPU 的位置编码和缓存写入。32 个位置、4 个头、128 个通道，共比较 16,384 个写入值：

- FP16 缓存：融合与未融合的 GPU 结果有 3 个半精度数不同，最大绝对差为 0.0625；3 个都是相邻的 FP16 表示值。
- FP32 缓存：融合与未融合的 GPU 结果逐位一致。
- 对这 3 个不同值，GPU 的 FP32 结果都恰好位于相邻 FP16 数值的中点。未融合结果与将该 FP32 输出离线按最近偶数规则转换成 FP16 的结果一致；融合的直接 FP16 输出在这 3 点选择了另一侧。

这些观察与舍入边界解释相符，但尚未定位着色器、编译器或驱动的具体指令行为，也不足以判定哪条路径在整个模型上更正确。最终 logits 的变化可能受后续多层运算放大；独立算子中的这 3 点不能被直接证明就是完整模型分数变化的全部原因。

为补充覆盖，复用同一 K 张量并人为将 32 个位置设在 1024–1055 和 4096–4127：FP16 融合与未融合分别有 1 个和 0 个值不同，FP32 两组均逐位一致。因为输入张量来自短输入，只改变了位置编号，这不是实际长上下文模型测试。

## 可选绕行方案

新增默认关闭的 `GGML_VK_EXPERIMENTAL_UNFUSED_ROPE_F16=1`：在 ARM GPU 上，仅当 `ROPE_VIEW_SET_ROWS` 的目标为 FP16 时放弃该融合，改为分别执行位置编码和缓存写入；不关闭其他融合。它是实验选项，并非对驱动错误的通用修复。

独立测试确认：该开关下 FP16 结果与未融合 GPU 路径逐位一致；FP32 缓存仍使用融合且结果与开关关闭时逐位一致。在 47 token 数学输入上，该开关的完整 GPU 词表分数与单独关闭 ROPE 融合、以及关闭全部融合的结果逐位一致，其他两类融合仍开启。

与此前的选择性 FP32 矩阵选项同时启用时，数学和中文样本均完成完整 GPU 推理；与只启用选择性矩阵选项相比，两条样本的 softmax 总变差分别约 0.017 和 0.022，首选 token 均相同。这是分布差异而非准确率结论。

另一种无需增加本次融合绕行开关的对照方式是使用 llama.cpp 的 `-ctk f32` 设置 FP32 K 缓存；本机仍需要此前建立的 Vulkan 兼容及大输出矩阵实验方案。在本次 256 个缓存单元、28 层的配置下，K 缓存从约 7 MiB 增至 14 MiB，K+V 缓存从约 14 MiB 增至 21 MiB；更长上下文的占用会增加。

## 初步生成速度

同一 5 token 提示词、16 token 连续生成、完整 GPU、关闭 Flash Attention；每组两次，表中为日志记录的生成阶段 token/秒。两次运行前后电池传感器约 26.0–27.5°C；没有固定设备频率或后台负载。

| 配置 | 两次生成速度（token/秒） |
|---|---:|
| 默认融合、FP16 K 缓存 | 0.57、0.56 |
| FP16 缓存，仅绕开 ROPE 融合 | 0.56、0.57 |
| FP32 K 缓存、默认融合 | 0.57、0.55 |

只测一次的“选择性 FP32 矩阵 + FP16 ROPE 融合绕行”组合为 0.56 token/秒。这些短测试不足以判断长上下文性能或稳定性。

## 复现和证据

在当前手机隔离构建中，保留先前运行命令的两个模型卸载开关后，可在新进程设置：

```sh
export GGML_VK_EXPERIMENTAL_LARGE_Q5_MAT=1
export GGML_VK_EXPERIMENTAL_UNFUSED_ROPE_F16=1
# 可选：此前的选择性矩阵精度实验
export GGML_VK_EXPERIMENTAL_MALI_FP32_QUANTS=1
```
